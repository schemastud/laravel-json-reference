# Dereferencers

A reference in this family points at a node by its `@id`, and it carries a **handle** naming who
can follow it: a corpus of fragments, a web page, another tenant's knowledge, a configuration
schema. `jsonref.dereferencers` maps each handle to the **dereferencer** that knows how to resolve
references of that kind. Resolution dispatches on the handle alone, never on what shape the node
happens to have.

## What a dereferencer is

A `Dereferencer` has two methods: `handle()`, the name it answers for, and `dereference()`, which
takes a `Ref` (anything with a `target()` `NodeId`) and a `ResolutionPolicy`, and returns whatever
the reference resolves to.

```php
use Schemastud\JsonReference\Dereferencer;
use Schemastud\JsonReference\Ref;
use Schemastud\JsonReference\ResolutionPolicy;

final class ArticleDereferencer implements Dereferencer
{
    public function handle(): string
    {
        return 'articles';
    }

    public function dereference(Ref $ref, ResolutionPolicy $policy): mixed
    {
        return Article::where('node_id', (string) $ref->target())->firstOrFail();
    }
}
```

In a JSON document, the `x-dereference` keyword carries the handle beside the node's `@id`, so a
reader can tell which dereferencer to ask without knowing anything else about the node.

## Registering

This package binds a shared, empty registry, and only if nothing else has. Other packages and your
application add to that one instance by extending the binding. Registering a dereferencer keys it
by its own `handle()`:

```php
use Schemastud\JsonReference\DereferencerRegistry;

public function register(): void
{
    $this->app->extend(DereferencerRegistry::class, fn (DereferencerRegistry $registry, $app) => $registry
        ->register($app->make(ArticleDereferencer::class)));
}
```

`extend()` runs when the registry is first resolved, so registrations stay lazy, and a
dereferencer with constructor dependencies can be built from the container.

The [**duplicate-key policy**](/beam/docs/foundations/registries#key-policies) is
**supersede**: a dereferencer registered under a handle that is taken replaces the earlier one,
which is how an application overrides a package's resolver for a handle.

## Reading it

`for($handle)` returns the dereferencer for a handle, or throws `UnknownDereferencer`. Catch that
exception by name to turn an unknown handle from a request into a client error rather than a
server error. `handles()` lists the registered handles.

## Following a reference, captured

This example registers a dereferencer for the `articles` handle, then follows a node that names an
article by its `@id`. The registry's keys come back absolute (`jsonref.dereferencers.articles`),
while `handles()` gives them back as you registered them. The JSON below is the real output of the
PHP beside it: the package captures it, and its test suite re-runs the example on every run, so
the two can't drift apart.

```php
use Schemastud\JsonReference\Dereferencer;
use Schemastud\JsonReference\DereferencerRegistry;
use Schemastud\JsonReference\NodeId;
use Schemastud\JsonReference\Ref;
use Schemastud\JsonReference\ResolutionPolicy;
use Schemastud\JsonReference\ResolveAll;
use Schemastud\JsonReference\Vocabulary;

// A dereferencer for the `articles` handle. A real one would query a store by the node's @id.
$articles = new class implements Dereferencer
{
    public function handle(): string
    {
        return 'articles';
    }

    public function dereference(Ref $ref, ResolutionPolicy $policy): mixed
    {
        return ['@id' => (string) $ref->target(), 'title' => 'Why handles, not shapes'];
    }
};

$registry = app(DereferencerRegistry::class)->register($articles);

// The node a document carries in place of the article: its @id, and the handle that can follow it.
$node = [Vocabulary::Id => 'nod_01JC0ARTICLE0000000000002', Vocabulary::Dereference => 'articles'];

$ref = new class(NodeId::fromString($node[Vocabulary::Id])) implements Ref
{
    public function __construct(private NodeId $id) {}

    public function target(): NodeId
    {
        return $this->id;
    }
};

return [
    'keys' => array_map('strval', $registry->keys()),
    'handles' => $registry->handles(),
    'node' => $node,
    'resolved' => $registry->for($node[Vocabulary::Dereference])->dereference($ref, new ResolveAll),
];
```
